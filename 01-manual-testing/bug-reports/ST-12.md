# ST-12: [Checkout] Typing in Last Name overwrites First Name for problem_user, blocking checkout

| Severity | Priority | Test case | Account | Environment |
| --- | --- | --- | --- | --- |
| Critical | High | CHK-01 | problem_user | Windows 11 · Chrome 155 · 1920×1080 |

## Preconditions
1. Logged in as problem_user
2. Cart empty
3. On Inventory page

## Steps to reproduce

1. Add Sauce Labs Backpack to the cart.
2. Click the cart icon.
3. Click Checkout.
4. Enter Jane in First Name.
5. Click the Last Name field and type Doe.

## Expected result
First Name stays as Jane.
Last Name shows Doe.

## Actual result
Last Name stays empty.
Each letter typed in Last Name replaces the value in First Name.
Only one letter remains in First Name at a time.
Checkout cannot continue.

## Evidence

[CHK-01 problem_user video: typing in Last Name overwrites First Name](../evidence/CHK-01_problem_user.mp4)

## Impact
The user cannot complete checkout or make a purchase. This blocks the core flow for problem_user and also affects CHK-06, CHK-07, and CHK-09 for this account.

## Suggested action
Check that the Last Name field writes to its own value rather than to First Name.
